# AEGIS

Florida traffic-stop companion. Record the stop, the script, and the law.

## Open the app

https://sonyajo42.github.io/stop-right/

Send that link in Messenger. The other person taps it. It opens in their phone browser.

To use it like an app: open the link, then Add to Home Screen (Safari Share, or Chrome menu → Install / Add to Home screen).

Not legal advice. Florida law as of 2026.
